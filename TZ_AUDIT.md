# Сверка с обновлённым ТЗ

Проверено по `ТЗ_HackAlem_AI_ассистент_ekt.kz_5_часов (1).md` на 23 сентября 2026 года. Файл ТЗ использован как перечень требований; реальные секреты в репозиторий не перенесены.

| Часть | Статус | Подтверждение |
|---|---|---|
| 1. Основа и каталог | Выполнено для MVP | FastAPI, backend Basic Auth, список/страницы/детали, нормализация, тайм-ауты, понятные ошибки и demo-набор. Реальный API отвечал на read-only запросы. |
| 2. Чат и OpenAI | Выполнено для MVP | Официальный Python SDK, Responses API, отдельный prompt, Pydantic Structured Output, проверка ID по backend-результатам, явный offline режим. Live smoke завершился успешно. |
| 3. Аналоги и demo cart | Выполнено для проверяемых данных | Кандидаты только из каталога или явно маркированного demo-набора; требуется общая характеристика и подтверждённый остаток. Корзина меняется после отдельного подтверждения и свежей проверки количества. Реальной записи в ekt.kz нет. |
| 4. Сессии и UX | Выполнено для MVP | SQLite история и корзина по session ID, загрузка/пустые результаты/ошибки, desktop/mobile проверка, mock-тесты полного сценария. |
| 5. Воспроизводимость | Выполнено | Чистая установка из lock-файла и HTTP-запуск проверены, четыре demo-состояния, live и offline smoke, встраиваемая версия, README, четырёхминутный сценарий. |

Оставшиеся границы прототипа:

- Поиск по свободному тексту охватывает первые три страницы API; точный числовой ID можно запросить напрямую. Полное индексирование всего каталога требует отдельной доработки.
- Если исходной позиции нет в результатах и нет её характеристик, надёжное сравнение аналогов невозможно: помощник просит уточнение. Совместимость предложенного аналога нельзя гарантировать только по совпавшим полям.
- Структура ответа и ID модели проверяются программно; каждую фактическую фразу свободного текста модели автоматически доказать нельзя. Для решения о покупке нужно сверить карточку товара.
- Встраивание подготовлено как iframe-прототип. Размещение на production-сайте ekt.kz и его политика CSP/хранения сессии не проверялись.
- Из API каталога подтверждены только read endpoints. Реальный cart API/SDK и безопасный handoff не предоставлены; оформление заказа не реализовано. Локальный session ID не является авторизацией покупателя.
- Лимиты частоты запросов ekt.kz не опубликованы в доступных материалах и не проверялись нагрузочным тестом. Backend ограничивает число страниц и параллельных запросов деталей.
- Исторический коммит второй части имеет название `feat: add grounded product chat`, потому что обновлённое ТЗ появилось позже. Облачная интеграция была доведена в коммите четвёртой части; опубликованную историю без force-push не переписывали.
