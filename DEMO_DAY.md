# Четырёхминутная демонстрация

Перед выступлением заполните локальный `.env` учётными данными каталога, `OPENAI_API_KEY` и `OPENAI_MODEL`, затем запустите основной сервер по README на порту 8000. Выполните `.\.venv\Scripts\python.exe -m scripts.live_smoke`: ожидаются `Catalog: OK` и `OpenAI Responses API: OK`. Не показывайте `.env` или ключ в терминале и браузере. Если live-проверка не прошла, не называйте резервный режим работающей интеграцией OpenAI.

Для гарантированного показа аналога откройте второй PowerShell в корне проекта и запустите отдельный **offline demo** на порту 8001:

```powershell
$env:EKT_API_USERNAME=''
$env:EKT_API_PASSWORD=''
$env:OPENAI_API_KEY=''
$env:OPENAI_MODEL=''
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8001
```

Это вымышленные товары и локальные ответы без OpenAI; не смешивайте их с результатами live-каталога. Отдельные вкладки `http://127.0.0.1:8000` и `http://127.0.0.1:8001` должны заранее показывать соответственно `Live-каталог · OpenAI API` и `Демо-каталог · локальный ответ`.

| Время | Что показать | Что сказать |
|---|---|---|
| 0:00–0:40 | Главная страница live-режима | «Покупателю нужны характеристики и наличие без ожидания менеджера. Ассистент получает данные только через серверный каталог». |
| 0:40–1:30 | Спросить `515291`; показать карточку и метку `OpenAI API` | «Вопрос и релевантные поля карточки отправляются облачной модели. Ответ имеет строгую структуру, а ID товара сверяет backend». Если карточка изменилась, выберите актуальный ID из списка. |
| 1:30–2:20 | Спросить `Добавь в корзину 200300285_ 1 шт`, открыть пустую demo cart, вернуться и ответить `Подтверждаю` | «Намерение купить не является подтверждением. Только отдельный ответ вызывает свежую проверку товара и остатка, затем запись в локальную demo cart». Проверьте артикул и остаток заранее; при изменении выберите другую доступную позицию. |
| 2:20–3:20 | Перейти на подготовленную вкладку 8001, спросить `DEMO-OUT`; показать `DEMO-ALT` и общие характеристики | «Это отдельно помеченный резервный набор: он воспроизводит отсутствие товара и подбор аналога. Здесь нет ни live ekt.kz, ни OpenAI». Можно показать `DEMO-PARTIAL` как пример отсутствующих полей. |
| 3:20–4:00 | Схема в README и страница `/cart` | «Basic Auth и OpenAI key остаются на backend. Корзина прототипа не изменяет ekt.kz; настоящая интеграция требует официального write API/SDK или согласованного перехода». |

Перед каждым новым показом нажмите кнопку сброса диалога. Уже добавленная demo cart сохраняется в рамках браузерной сессии; для визуально пустой корзины используйте новую приватную вкладку или новый профиль браузера. Никаких платёжных данных не вводите.
